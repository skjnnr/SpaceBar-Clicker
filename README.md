# Spacebar Clicker

A simple browser clicker game inspired by the supplied screenshot.

## Play locally
Open `index.html` in Chrome.

## Publish with GitHub Pages
1. Create a new GitHub repository.
2. Upload `index.html`, `style.css`, and `game.js` to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Choose your `main` branch and `/ (root)`, then save.
6. GitHub will provide the public game URL after deployment.

Progress is stored in the browser with localStorage.
